# API для онлайн-записи (zapis.diskimira.com)

Сайт онлайн-записи (booking_service) обращается к платформе хранения со своего сервера: ищет хранения клиента,
заказывает колёса к выдаче под запись, обменивается гаражом и управляет доверенными лицами при машине
(семейный аккаунт). Браузер клиента в платформу не ходит.

## Подключение

- Базовый адрес: `https://wh.diskimira.com/api/v1/booking/`, формат — JSON.
- Ключ: «Администрирование → Интеграция → Ключи API», «Для: Онлайн-запись», IP — статический адрес сервера записи.
  Или командой: `php artisan onec:key "Онлайн-запись" --scope=booking --ips=<IP сервера записи>`.
  Ключ передаётся в `Authorization: Bearer wk_…` или `X-Api-Key`. Ключ 1С в этот раздел не пускает, и наоборот.
- Телефон — тот, что клиент подтвердил кодом из SMS на сайте записи. Сравнение только точное (+7 и 10 цифр).
- POST/PATCH с заголовком `Idempotency-Key` безопасно повторять.
- Каждый поиск пишется в журнал `api_access_log` (ключ, телефон, госномер, IP, сколько найдено).

## Семейный аккаунт (вариант Г)

Машина — главное звено. Владелец — `vehicles.client_id`. Доверенные лица (`vehicle_persons`) видят машину в онлайн-записи,
сдают её колёса на свой договор и забирают их. Добавляют их сотрудник в карточке авто или сам владелец в личном
кабинете онлайн-записи. При смене владельца доверенности отзываются, при объединении клиентов — переходят.

## Методы

| Метод | Что делает |
| --- | --- |
| `GET lookup?phone=&plate=&store_code=` | Машины клиента (свои — `role: owner`, доверенные — `role: trusted`), комплекты гаража, колёса на хранении. `plate` — проверить ещё одну машину: если она чужая, в `foreign_plate` только «хранение есть / нет». `store_code` — магазин записи, от него считается `ready_from` |
| `POST garage` | Гараж из записи: `{phone, full_name, vehicles: [{ref, plate, make, model, year, wheels: [{ref, season, studded, tire_size, brand, model, rim_type}]}]}`. Хранение главнее: добавляются только новые машины и комплекты сезонов, которых нет; пустые поля машины дополняются. Нет клиента — создаётся. Машина с госномером чужого клиента — `status: foreign`, не трогается |
| `POST orders` | Заказ комплекта к выдаче под запись: `{booking_code, set_id, store_code, starts_at, phone}`. Проверяется, что телефон — владелец, доверенное лицо или клиент договора |
| `PATCH orders/{booking_code}` | Перенос записи: `{starts_at, store_code?}` — новая дата выдачи или перезаказ в другой магазин |
| `DELETE orders/{booking_code}` | Отмена записи — заказ снимается, если колёса ещё не выданы |
| `GET orders/{booking_code}` | Состояние заказа и комплекта |
| `POST vehicles/{id}/persons` | Владелец добавляет доверенное лицо: `{phone (владельца), person_phone, person_name}` |
| `DELETE vehicles/{id}/persons/{person_id}?phone=` | Отзыв: владелец или само доверенное лицо |

Комплект на хранении в ответе `lookup`:

```json
{
  "set_id": "…", "qr_code": "000123", "contract_number": "000123", "contract_status": "open",
  "season": "winter", "title": "Зима", "tire_size": "205/55 R16 94H", "qty": 4, "with_rims": true,
  "state": "in_storage", "state_label": "На хранении", "orderable": true, "booking_code": null,
  "ready_from": "2026-11-07T12:00:00+05:00", "storage_until": "2027-04-30", "paid_until": "2027-04-30",
  "debt": 0, "warnings": []
}
```

`state`: `in_storage`, `ordered`, `ready_in_store`, `other`. Адрес ячейки наружу не отдаётся.
`debt` — долг по 1С плюс плата за хранение после срока; `warnings` — что показать клиенту (запись разрешена).

## Когда колёса будут в магазине

`ready_from`: уже в магазине записи или в том же здании — сразу; иначе — через `BOOKING_DELIVERY_DAYS` дней
(по умолчанию 1) к `BOOKING_DELIVERY_TIME` (по умолчанию 12:00, местное время).
